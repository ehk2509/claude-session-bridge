# Claude Session Bridge v0.3.2 — VS Code beta

**Marketplace icon compatibility fix** for `ElyesHkiri.claude-session-bridge-vscode`.

The neon bridge artwork is unchanged in design but resized from 1254 × 1254 to **512 × 512 pixels**, preserving transparency. Microsoft Marketplace rejected v0.3.1's image because icon dimensions cannot exceed 1024 × 1024.

### Included
- Fixed extension icon `vscode-extension/media/icon.png`.
- CI check preventing oversized Marketplace icons.
- No application behavior or account-handling changes since v0.3.1.
- Publisher remains `ElyesHkiri`, extension version is `0.3.2`.
