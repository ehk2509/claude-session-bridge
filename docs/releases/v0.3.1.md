# Claude Session Bridge v0.3.1 — VS Code beta

This update registers the new **neon chat-bridge logo** and packages the extension under **Marketplace publisher `ElyesHkiri`**.

- VS Code Marketplace ID: `ElyesHkiri.claude-session-bridge-vscode`
- New icon: `media/icon.png` (PNG, 1254 × 1254)
- Existing commands, session handoff workflow, backup integrity, and diagnostics are unchanged from v0.3.0.
- Repository owner remains `ehk2509`; VS Code extension CLI package remains independent at v0.1.0.

Download `claude-session-bridge-vscode-0.3.1.vsix` below and install via **Extensions → ... → Install from VSIX...**. Verify using the attached `SHA256SUMS` file with `sha256sum -c SHA256SUMS`.

Marketplace publishing is a **separate manual GitHub Actions workflow** and requires an authorized `VSCE_PAT` secret for the `ElyesHkiri` publisher. A GitHub Release alone does not mean the extension is on Marketplace.
