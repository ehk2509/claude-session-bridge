# Claude Session Bridge v0.3.0 — VS Code beta

**Local-first Claude Code conversation handoff across accounts.** The companion extension supports guided account switching inside VS Code. The separate command-line tool remains at version 0.1.0.

## What's new

- **Quick Account Handoff** with a status-bar shortcut and confirmation of the most recently saved session.
- Private transcript backups with SHA-256 verification before recovery.
- **Diagnose Session Recovery** for missing transcripts, workspace/config mismatches and damaged backups without disclosing conversation contents.
- Pending handoffs survive VS Code reloads; backups are retained after confirmation.
- Cross-platform CI tests and a reproducible VSIX build.

## Installation

Download `claude-session-bridge-vscode-0.3.0.vsix` from the **Assets** section below. In VS Code open **Extensions → ... → Install from VSIX...** and select the file. Install the official Anthropic Claude Code extension too.

Use the Command Palette to run **Claude Session Bridge: Quick Account Handoff**, or click **Claude handoff** in the bottom status bar.

The `SHA256SUMS` asset can be used to verify the VSIX:
```bash
sha256sum -c SHA256SUMS
```

## Beta limitations

- A successful two-account session continuation was demonstrated on Linux with an earlier companion version (v0.2.0). The v0.3.0 workflow has automated tests, but cross-account compatibility across all VS Code/Claude Code installations remains unverified.
- The tool **does not switch accounts automatically**. Sign out and sign in through the official Claude Code extension.
- The bridge suggests the latest saved conversation; it cannot identify the currently active chat with certainty.
- Claude Code must be able to reopen the saved local session. Compacted conversations may retain a summary rather than full earlier model context.
- Local backups may contain sensitive code, prompts or tool outputs. Do not publish them.
- This project is not affiliated with Anthropic and does not modify tokens, subscriptions or quotas.
